# CLAUDE.md

## Style

- **Never use em dashes (—), ever.** Zero exceptions: page copy, UI strings, error messages, metadata, automated/transactional emails, code comments, commit messages, and any other text in this repo. Use a comma, period, colon, semicolon, or parentheses instead, whichever reads most naturally. This has been asked for repeatedly across BJ's projects; treat it as a hard constraint, not a style preference.
